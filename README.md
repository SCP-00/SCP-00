## 🛠️ How I build

1. **Define the problem** — who it is for, what "done" means, which constraints are non-negotiable.
2. **Model before code** — entities, states and the data contract between components.
3. **Direct the agents** — scoped prompts, guardrails and review after every generated block.
4. **Prove it works** — automated tests, manual QA of edge cases, and documentation someone else can follow.
